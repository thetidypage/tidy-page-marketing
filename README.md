Public marketing images for The Tidy Page (Pinterest pin images). Do not rename or delete files: scheduled pins link to them.

## Free tools

`tools/puppy-age-calculator/` is a static puppy age calculator (one HTML file, no trackers). GitHub Actions deploys the `tools/` folder to GitHub Pages. Setup notes are in `.github/workflows/pages.yml`.

Once Pages has published from that workflow, the calculator is at:

https://thetidypage.github.io/tidy-page-marketing/puppy-age-calculator/
